# Modelo 3D de Chispa

Coloca aquí el archivo **`mascot.glb`** y recarga la página. El cargador lo detecta automáticamente, lo escala, lo centra y sustituye al personaje procedural.

```text
assets/models/mascot.glb
```

Si el archivo no existe, la web usa el personaje procedural sin dar errores.

Requisitos técnicos y nombres de nodos: [`docs/MODELO_3D.md`](../../docs/MODELO_3D.md).
